# Actividades-programacion-analitica
Este repositorio reúne las prácticas y ejercicios desarrollados durante el curso como evidencia del proceso de aprendizaje en programación analítica con Python. A través de las actividades realizadas en clase, se aplicaron conceptos fundamentales de programación y análisis de datos, fortaleciendo progresivamente la capacidad para trabajar con estructuras de datos, realizar operaciones y transformaciones, filtrar y agrupar información, integrar diferentes fuentes de datos y obtener resultados a partir de los datos analizados.

Los ejercicios permitieron llevar los conocimientos teóricos a situaciones prácticas, desarrollando habilidades para plantear problemas, construir soluciones mediante código, interpretar resultados y detectar errores durante el proceso de programación. Asimismo, el acompañamiento del docente y la práctica constante facilitaron la comprensión de herramientas y librerías de Python orientadas al análisis de datos, especialmente pandas, numpy y otras herramientas utilizadas durante el curso.

En conjunto, este repositorio refleja el proceso de aprendizaje y la evolución en el manejo de Python, desde ejercicios básicos de programación hasta actividades de análisis y manipulación de datos, destacando la importancia de la práctica como parte fundamental del desarrollo de habilidades en programación analítica.
